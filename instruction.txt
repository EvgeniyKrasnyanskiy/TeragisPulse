========================================================================
    ИНСТРУКЦИЯ ПО ЗАПУСКУ TERAGIS NOTIFIER НА LINUX (XUBUNTU)
========================================================================

Teragis Notifier — это фоновое приложение для моментального отображения
уведомлений о готовности планов лечения. Оно полностью адаптировано
для работы на старых версиях Linux (включая Xubuntu 16.04 с Python 3.5).

Все современные Unicode-эмодзи автоматически фильтруются на уровне кодов
символов, что гарантирует 100% стабильность интерфейса и исключает сбои.
Размер файлов отладочного логирования автоматически контролируется (файл
notifier_debug.txt очищается при достижении 1 МБ), предотвращая переполнение диска.

------------------------------------------------------------------------
🚀 ШАГ 1. ПЕРЕНОС ФАЙЛОВ НА КОМПЬЮТЕР
------------------------------------------------------------------------
Скопируйте всю папку 'TeragisPulse_Linux' с флешки на рабочий стол 
или в домашнюю папку на целевом компьютере с Xubuntu.

------------------------------------------------------------------------
📦 ШАГ 2. УСТАНОВКА ЗАВИСИМОСТЕЙ В СИСТЕМЕ
------------------------------------------------------------------------
1. Откройте терминал на машине Xubuntu.
2. Установите pip (пакетный менеджер) и системную графическую библиотеку tk:
   
   sudo apt update && sudo apt install python3-pip python3-tk -y

3. Перейдите в скопированную папку:
   
   cd ~/Desktop/TeragisPulse_Linux/db_notifier

4. Установите библиотеки Python одной командой:
   
   pip3 install --user -r requirements.txt

   *(Если ранее была установлена несовместимая версия python-dotenv, эта 
   команда автоматически заменит её на совместимую с Python 3.5 версию 0.19.2)*

------------------------------------------------------------------------
🔌 ШАГ 3. НАСТРОЙКА ПОДКЛЮЧЕНИЯ И ФАЙЛ .env (НЕОБЯЗАТЕЛЬНО)
------------------------------------------------------------------------
Файл '.env' теперь НЕОБЯЗАТЕЛЕН. Приложение само выполняет поиск сервера:
- **На клиенте (АРМ-оператора)**: программа автоматически просканирует
  сеть и найдет IP-адрес вашего сервера PostgreSQL на порту 5432.
- **На самом сервере БД**: программа автоматически подключится к
  локальной базе данных (localhost / 127.0.0.1).
- Если ваша сеть имеет сложную структуру, вы можете принудительно прописать
  адрес сервера, создав файл '.env' в папке 'db_notifier':
  DB_HOST=192.168.177.1
  DB_PORT=5432
  DB_NAME=veri
  DB_USER=tera
  DB_PASS=tera123

------------------------------------------------------------------------
⚡ ШАГ 4. ЗАПУСК ПРИЛОЖЕНИЯ
------------------------------------------------------------------------
Вы можете запускать приложение двумя способами:

**Вариант А. Запуск в один клик (Рекомендуется)**
1. Дайте права на выполнение файлу запуска 'start_notifier.sh':
   В терминале перейдите в корень папки 'TeragisPulse_Linux' и выполните:
   
   chmod +x start_notifier.sh

2. Теперь вы можете запускать приложение двойным кликом по файлу 
   'start_notifier.sh' прямо из файлового менеджера!

**Вариант Б. Запуск через терминал**
Перейдите в папку 'db_notifier' и запустите скрипт напрямую:
   
   python3 tnotif.py

------------------------------------------------------------------------
🔄 ШАГ 5. ДОБАВЛЕНИЕ В АВТОЗАПУСК XUBUNTU (XFCE)
------------------------------------------------------------------------
Чтобы уведомления запускались автоматически при каждом включении компьютера:

1. Откройте **Меню приложений Xubuntu** -> **Настройки** -> **Сеансы и запуск**.
2. Перейдите на вкладку **Автозапуск приложений** (Application Autostart).
3. Нажмите кнопку **Добавить** (+).
4. Заполните поля формы:
   - **Имя**: Teragis Notifier
   - **Описание**: Фоновые уведомления о планах лечения
   - **Команда**: Укажите полный путь к файлу start_notifier.sh, например:
     /home/tera/Desktop/TeragisPulse_Linux/start_notifier.sh
     *(или используйте кнопку «Обзор» для выбора этого файла)*
5. Нажмите **ОК**.

Теперь при включении компьютера Teragis Notifier тихо запустится в фоне 
и свернется в системный трей в углу экрана.
