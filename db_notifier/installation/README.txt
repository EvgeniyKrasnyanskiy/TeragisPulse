ИНСТРУКЦИЯ ПО УСТАНОВКЕ TERAGIS NOTIFIER НА LINUX (XUBUNTU 16.04)
================================================================

В корне накопителя подготовлены две папки для различных условий развёртывания:
1. "online"  — Установка при наличии доступа к интернету (например, через USB-модем с телефона).
2. "offline" — Установка полностью без интернета (все зависимости уже скачаны на флешку).

Перед установкой обязательно скопируйте файл конфигурации настроек `.env` (если он у вас есть) в папку `db_notifier/` соответствующего дистрибутива, либо настройте его после установки.

----------------------------------------------------------------
ВАРИАНТ 1: Установка с интернетом (Папка "online")
----------------------------------------------------------------
Этот способ автоматически установит и настроит все компоненты через репозитории Ubuntu.
Скрипт установки умеет автоматически переключать репозитории Ubuntu 16.04 на архивные сервера (old-releases.ubuntu.com) и временно настраивать Google DNS, если на сервере не работает DNS. После завершения установки все настройки сети и репозиториев возвращаются в исходное состояние!

Инструкция:
1. Подключите интернет к серверу (например, раздайте интернет со смартфона через USB-кабель в режиме "USB-модем").
2. Откройте терминал в папке `online/`.
3. Сделайте скрипт исполняемым:
   chmod +x install_online.sh
4. Запустите установку:
   ./install_online.sh
5. При запросе введите пароль `sudo` (пользователя tera).
6. После завершения ярлык запуска появится на Рабочем столе.

----------------------------------------------------------------
ВАРИАНТ 2: Установка БЕЗ интернета (Папка "offline")
----------------------------------------------------------------
Этот способ устанавливает все необходимые системные пакеты (включая tkinter для интерфейса и pip3) и библиотеки Python локально с флешки.

Инструкция:
1. Откройте терминал в папке `offline/`.
2. Сделайте скрипт исполняемым:
   chmod +x install_offline.sh
3. Запустите установку:
   ./install_offline.sh
4. При запросе введите пароль `sudo` (пользователя tera).
5. Скрипт установит системные пакеты .deb из папки `packages/deb` и библиотеки Python из папки `packages/pip`.
6. После завершения ярлык запуска появится на Рабочем столе.

----------------------------------------------------------------
Управление приложением
----------------------------------------------------------------
* Запуск:
  Нажмите дважды на ярлык "Teragis Notifier" на Рабочем столе.
  Если система спросит, выберите "Запустить" или "Сделать исполняемым и запустить".

* Автозапуск:
  Приложение автоматически прописывается в автозапуск Xubuntu (XFCE) и будет запускаться при каждом входе пользователя в систему.

* Удаление (Деинсталляция):
  Для полного удаления программы перейдите в папку установленного приложения (на Рабочем столе папка `TeragisNotifier`) и запустите скрипт деинсталляции через терминал:
  cd ~/Desktop/TeragisNotifier
  ./uninstall.sh
  Это полностью очистит автозапуск, кэш, ярлык на рабочем столе и удалит саму папку приложения.
