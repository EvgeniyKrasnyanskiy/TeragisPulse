========================================================================
    ИНСТРУКЦИЯ ПО ЗАПУСКУ И УПРАВЛЕНИЮ TERAGIS NOTIFIER НА LINUX
========================================================================

Teragis Notifier — это фоновое приложение для моментального отображения
уведомлений о готовности планов лечения. Приложение полностью адаптировано
для работы на старых версиях Linux (включая Xubuntu 16.04 с Python 3.5).

Приложение работает без значка в классическом трее, используя легкую
плавающую кнопку управления (оверлей), что гарантирует 100% совместимость
со старыми версиями Xfce/X11 без установки сторонних нестабильных библиотек.

Все современные Unicode-эмодзи автоматически фильтруются на уровне кодов
символов для стабильности GUI. Персональные данные пациентов (ФИО) в файле
отладочного логирования автоматически маскируются для соблюдения ФЗ-152.

------------------------------------------------------------------------
🚀 ШАГ 1. ПЕРЕНОС ФАЙЛОВ НА КОМПЬЮТЕР
------------------------------------------------------------------------
Скопируйте папку 'TeragisPulse_Linux' с флешки или диска E: в домашнюю 
папку или на рабочий стол целевого компьютера с Xubuntu.

------------------------------------------------------------------------
📦 ШАГ 2. АВТОМАТИЧЕСКАЯ УСТАНОВКА ЗАВИСИМОСТЕЙ
------------------------------------------------------------------------
1. Откройте терминал на машине Xubuntu.
2. Перейдите в скопированную папку:
   
   cd ~/TeragisPulse_Linux

3. Запустите скрипт установки зависимостей:
   
   ./install.sh

   *(Скрипт сам обновит системные пакеты, установит python3-tk и
   библиотеки Python в пространство пользователя)*

------------------------------------------------------------------------
🔌 ШАГ 3. НАСТРОЙКА ПОДКЛЮЧЕНИЯ И ФАЙЛ .env (НЕОБЯЗАТЕЛЬНО)
------------------------------------------------------------------------
Файл '.env' НЕОБЯЗАТЕЛЕН. Приложение само выполняет поиск сервера:
- **На клиенте (АРМ-оператора)**: программа автоматически просканирует
  сеть и найдет IP-адрес вашего сервера PostgreSQL на порту 5432.
- **На самом сервере БД**: программа автоматически подключится к
  локальной базе данных (localhost / 127.0.0.1).
- Если ваша сеть имеет сложную структуру, вы можете принудительно прописать
  адрес сервера, создав файл '.env' в папке 'db_notifier':
  DB_HOST=192.168.177.1
  DB_PORT=5432
  DB_NAME=veri
  DB_USER=tera
  DB_PASS=tera123

------------------------------------------------------------------------
⚡ ШАГ 4. ЗАПУСК ПРИЛОЖЕНИЯ
------------------------------------------------------------------------
Для запуска приложения дважды кликните по файлу 'start.sh' в файловом
менеджере или выполните в терминале:

./start.sh

При запуска на экране (по центру вверху) появится маленькая темная 
кнопка-кружок с буквой 'T' и цветным ободком статуса:
- Зеленый ободок — подключение к БД успешно установлено.
- Оранжевый ободок — идет поиск сервера или подключение.
- Красный ободок — сбой подключения к БД.

------------------------------------------------------------------------
🔄 ШАГ 5. ДОБАВЛЕНИЕ В АВТОЗАПУСК XUBUNTU
------------------------------------------------------------------------
Чтобы приложение автоматически запускалось при включении компьютера:
Просто запустите скрипт добавления в автозапуск в терминале:

./autostart.sh

Скрипт сам создаст нужный конфигурационный файл автозапуска в системе.

------------------------------------------------------------------------
🎮 УПРАВЛЕНИЕ И ГОРЯЧИЕ КЛАВИШИ
------------------------------------------------------------------------
1. **Перетаскивание**: Плавающую кнопку 'T' можно перетащить мышкой
   в любое удобное место экрана (она не выйдет за границы дисплея).
   Ее положение сохраняется автоматически и восстановится при перезапуске.
2. **Контекстное меню**: Кликните по кнопке 'T' (левой или правой кнопкой
   мыши) для вызова меню:
   - **История** — открывает окно со всеми уведомлениями за сегодня.
     Внизу окна истории есть кнопка «Закрыть» для закрытия этого списка.
   - **Скрыть** — скрывает кнопку управления с экрана. Приложение
     продолжает работать в фоне и выводить уведомления.
   - **Выход** — чтобы закрыть приложение полностью, **зажмите клавишу
     Shift** при открытом контекстном меню: пункт «Скрыть» изменится
     на «Выход».
3. **Кнопка «⚙» (шестеренка) на уведомлениях**: Если вы скрыли плавающую 
   кнопку, вы можете вернуть ее на экран, нажав на иконку шестеренки `⚙`
   в правом верхнем углу любой всплывающей карточки уведомления.
4. **Горячие клавиши**:
   - `Ctrl + Shift + H` — скрыть или показать плавающую кнопку.
   - `Ctrl + Shift + Q` — полностью закрыть программу (выход).
     *(Работает, когда любое окно приложения находится в фокусе)*
