# Teragis Notifier — АРМ-клиент уведомлений для оператора (Xubuntu)

Легковесный фоновый клиент для операционной системы Xubuntu, разработанный для моментального отображения готовности планов лечения пациентов. 

Приложение подключается к серверу PostgreSQL, слушает триггерный канал `series_changes` в реальном времени и выводит стильные всплывающие карточки в правом нижнем углу экрана.

---

## ✨ Основные возможности

1. **Zero-Configuration:** Автоматическое обнаружение сервера БД в локальной сети (поиск по каскаду: кэш -> localhost -> .env -> быстрое асинхронное сканирование подсети).
2. **Тост-карусель (Toast Stack):** Вывод до 5 карточек одновременно. Самая старая карточка удаляется досрочно при появлении 6-й.
3. **Автоисчезновение:** Карточки постепенно угасают и удаляются сами через 5 минут.
4. **Сворачивание в трей:** Приложение работает в фоне, прячется в системный лоток (трей) Xubuntu и имеет подсказку со статусом подключения БД при наведении мыши.
5. **Безотказность:** Автоматическое восстановление соединения с базой при сбоях сети (например, при перезагрузке роутера или сервера).

---

## 📋 Предварительные требования в Xubuntu (Linux)

Перед запуском убедитесь, что в системе установлен интерпретатор Python 3 и библиотека для работы с оконным интерфейсом `tkinter` (в Linux она ставится отдельно через пакетный менеджер):

```bash
sudo apt update
sudo apt install python3 python3-pip python3-tk -y
```

## 🚀 Установка и запуск

### Шаг 1. Перейдите в папку клиента и установите зависимости:
```bash
cd db_notifier
pip3 install -r requirements.txt
```

### Шаг 2. Запустите приложение:
```bash
python3 main.py
```
Приложение запустится в фоновом режиме, в правом нижнем углу трея Xubuntu появится иконка. При наведении на нее мыши отобразится статус: `Teragis Notifier: Подключено (IP сервера)` или `Поиск сервера...`.

---

## ⚙️ Ручная настройка (при необходимости)

По умолчанию программа сама находит сервер БД. Если ваша сеть имеет сложную структуру (СУБД находится в другой подсети) или вы хотите жестко прописать адрес, создайте в папке `db_notifier` файл `.env` со следующими параметрами:

```env
DB_HOST=192.168.177.1   # IP-адрес вашего сервера БД
DB_NAME=veri            # Имя базы данных
DB_USER=tera            # Логин
DB_PASS=tera123         # Пароль
DB_PORT=5432            # Порт
```

## 📦 Сборка в один исполняемый файл (PyInstaller)

Чтобы распространять приложение в виде одного-единственного файла, который можно запустить на любом компьютере с Xubuntu (или Windows) даже **без установленного Python**:

1. Установите PyInstaller:
   ```bash
   pip3 install pyinstaller
   ```

2. Соберите бинарный файл по готовому конфигурационному файлу сборки:
   ```bash
   pyinstaller db_notifier.spec
   ```

3. Исполняемый файл появится в папке `dist/db_notifier`. Перенесите его на любую станцию Xubuntu, дайте права на выполнение и запустите!
   ```bash
   chmod +x db_notifier
   ./db_notifier
   ```

## 🔄 Добавление в автозапуск Xubuntu (XFCE)

Чтобы уведомления запускались автоматически при каждом включении компьютера оператора:

1. Откройте **Меню приложений Xubuntu** -> **Настройки** -> **Сеансы и запуск**.
2. Перейдите на вкладку **Автозапуск приложений** (Application Autostart).
3. Нажмите кнопку **Добавить** (+).
4. Заполните поля:
   - **Имя:** `Teragis Notifier`
   - **Описание:** `Фоновые уведомления о готовности планов лечения`
   - **Команда:** Укажите путь к исполняемому файлу, например: `/home/operator/Desktop/db_notifier` (или `python3 /путь_к_папке/main.py`).
5. Нажмите **ОК**. Готово! Теперь при старте системы клиент тихо свернется в трей.
