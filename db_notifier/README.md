# Teragis Notifier — АРМ-клиент уведомлений для оператора (Xubuntu)

Легковесный фоновый клиент для операционной системы Xubuntu, разработанный для моментального отображения готовности планов лечения пациентов. 

Приложение подключается к серверу PostgreSQL, слушает триггерный канал `series_changes` в реальном времени и выводит стильные всплывающие карточки в правом нижнем углу экрана.

---

## ✨ Основные возможности

1. **Zero-Configuration:** Автоматическое обнаружение сервера БД в локальной сети (поиск по каскаду: кэш -> localhost -> .env -> быстрое асинхронное сканирование подсети).
2. **Тост-карусель (Toast Stack):** Вывод до 5 карточек одновременно. Самая старая карточка удаляется досрочно при появлении 6-й (жестко контролируемая ротация).
3. **Автоисчезновение:** Карточки постепенно угасают и удаляются сами через 5 минут благодаря стабильному глобальному таймеру.
4. **Плавающая кнопка управления (оверлей):** Приложение работает в фоне, прячется на экране в виде компактного интерактивного кружка с цветовой индикацией статуса подключения к БД и подсказкой при наведении мыши.
5. **История за сегодня:** Возможность открыть из контекстного меню кнопки (правый/левый клик -> «История») стильное темное окно со списком всех полученных за текущие сутки уведомлений с поддержкой прокрутки.
6. **Быстрое тестирование:** Наличие скрипта `test_gui.py` для мгновенной симуляции входящих уведомлений, проверки верстки (ширина карточек увеличена до 400px для предотвращения обрезки текста) и ускоренного автозакрытия (15 секунд).
7. **Безотказность:** Автоматическое восстановление соединения с базой при сбоях сети (например, при перезагрузке роутера или сервера).

## 📋 Предварительные требования в Xubuntu (Linux)

Перед запуском убедитесь, что в системе установлен интерпретатор Python 3 и библиотека для работы с оконным интерфейсом `tkinter` (в Linux она ставится отдельно через пакетный менеджер):

```bash
sudo apt update
sudo apt install python3 python3-pip python3-tk -y
```

---

## 🚀 Установка и запуск

### Шаг 1. Перейдите в папку клиента и установите зависимости:
```bash
cd db_notifier
pip3 install -r requirements.txt
```

### Шаг 2. Запустите приложение:
```bash
python3 tnotif.py
```
Приложение запустится в фоновом режиме, на экране появится плавающая круглая кнопка управления 'T'. Цвет её ободка показывает статус подключения к БД (зелёный — подключено, оранжевый — поиск, красный — ошибка), а при наведении мыши отображается всплывающая подсказка со статусом.

## ⚙️ Ручная настройка (при необходимости)

По умолчанию программа сама находит сервер БД. Если ваша сеть имеет сложную структуру (СУБД находится в другой подсети) или вы хотите жестко прописать адрес, создайте в папке `db_notifier` файл `.env` со следующими параметрами:

```env
DB_HOST=192.168.177.1   # IP-адрес вашего сервера БД
DB_NAME=veri            # Имя базы данных
DB_USER=tera            # Логин
DB_PASS=tera123         # Пароль
DB_PORT=5432            # Порт
```

## 📦 Сборка в один исполняемый файл (PyInstaller)

Чтобы распространять приложение в виде одного-единственного файла, который можно запустить на любом компьютере с Xubuntu или Windows даже **без установленного Python**:

### 🪟 Быстрая сборка для Windows:
Просто дважды кликните по файлу [build.bat](file:///d:/Users/physicist/Desktop/ken/TeragisPulse/db_notifier/build.bat) в папке `db_notifier`.
Скрипт автоматически:
1. Проверит наличие Python.
2. Установит `pyinstaller`, если он не установлен.
3. Скачает зависимости из `requirements.txt`.
4. Запустит сборку в один `.exe` файл без консоли по спецификации `tnotif.spec`.
5. Готовый файл сохранится в папке: `dist_win/TeragisNotifier.exe`.

### 🐧 Сборка для Linux (Xubuntu) с 32-битным интерпретатором:
Сборка линуксового бинарника выполняется с использованием 32-битной среды CPython из локальной папки `python`:

#### Вариант A. Сборка через WSL (после перезагрузки хост-системы Windows):
Выполните команду в терминале Windows:
```bash
wsl -d Ubuntu -- cd db_notifier && ../python/bin/python3 -m PyInstaller --clean --workpath="build_linux" --distpath="dist_linux" tnotif.spec
```

#### Вариант B. Сборка на целевой Xubuntu-машине:
1. Скопируйте проект на вашу Linux-машину.
2. Перейдите в папку клиента и запустите сборку:
   ```bash
   cd db_notifier
   ../python/bin/python3 -m PyInstaller --clean --workpath="build_linux" --distpath="dist_linux" tnotif.spec
   ```
3. Исполняемый 32-битный файл появится в папке `dist_linux/TeragisNotifier`. Дайте ему права на исполнение и запустите:
   ```bash
   chmod +x dist_linux/TeragisNotifier
   ./dist_linux/TeragisNotifier
   ```

## 🔄 Добавление в автозапуск Xubuntu (XFCE)

Чтобы уведомления запускались автоматически при каждом включении компьютера оператора, в Linux-версии достаточно запустить скрипт автозапуска:
```bash
./autostart.sh
```
Скрипт автоматически создаст `.desktop` файл в каталоге автозапуска системы (`~/.config/autostart/`). Теперь при старте системы оверлей появится вверху экрана по центру.
