# TeragisPulse

Современная система мониторинга и уведомлений для Teragis.

## Описание
Программа предназначена для визуализации текущего состояния очередей пациентов, автоматической генерации отчетов и отправки уведомлений в Telegram.

## Основные возможности
- **Мониторинг в реальном времени**: Отслеживание статусов пациентов (Planned, On Treatment, Completed).
- **Telegram Бот**: Уведомления о новых планах, рассылка отчетов, генерация Excel, прогноз конца смены.
- **Автоматические отчеты**: Генерация CSV и Excel-отчетов по запросу и расписанию.
- **Умная классификация**: Определение отделения по маске серии или по фамилии врача.
- **Индикация статуса БД**: Визуальный контроль подключения к PostgreSQL.
- **Управление прокси**: Автоматический запуск и остановка xray и xmtproto.

## Установка и запуск

### 1. Подготовка окружения
Рекомендуется использовать виртуальное окружение:
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка
Создайте файл `.env` для хранения секретов и `config.ini` для визуальных настроек.

### 3. Запуск
```bash
python teragis_pulse.py
```

## Структура проекта
- `teragis_pulse.py` — основной файл приложения (GUI на CustomTkinter).
- `database.py` — пул соединений и работа с PostgreSQL.
- `report_manager.py` — управление расписанием и логикой отчетов.
- `tg_bot_ws.py` / `tg_bot_xr.py` — реализация Telegram бота (WebS / XR).
- `tg_bot_ws_cmd.py` — обработчики команд бота.
- `proxy_manager.py` — управление внешними прокси-процессами.
- `identification.py` — логика разбора заметок и идентификации персонала.
- `constants.py` — справочники врачей и эмодзи.
- [TeragisNotifier](https://github.com/EvgeniyKrasnyanskiy/TeragisNotifier) — легковесный десктопный клиент (АРМ) для оператора на Xubuntu (вынесен в отдельный репозиторий).

## Команды Telegram Бота
- `/find_patient <запрос>` — Нечеткий поиск пациентов по ФИО с генерацией быстрых ссылок.
- `/patient_info <ФИО/ID>` — Детальная структурированная информация о пациенте и всех его курсах лечения.
- `/list [дата]` — Текущий список пациентов.
- `/summary <1/2/0> [дата]` — Сводка по пациентам (0 — Прочее).
- `/excel <1/2/0> <дата>` — Детальный Excel-отчет (0 — Прочее).
- `/msg_to_group <1/2> <текст>` — Сообщение в группу отделения.
- `/auth <user_id>` — Добавление администратора.
- `/summary_full` — Полный текстовый отчет по врачам.
- `/ping` — Проверка связи.
- `/help` — Справка.

## Дополнительные утилиты

### Teragis Notifier (АРМ оператора)
Проект легкого графического клиента для Xubuntu вынесен в отдельный репозиторий: [TeragisNotifier](https://github.com/EvgeniyKrasnyanskiy/TeragisNotifier).
Он в реальном времени оповещает операторов в процедурной о готовности новых лечебных планов через всплывающие карточки и системный трей.
