# TeragisPulse

Современная система мониторинга и уведомлений для Teragis.

## Описание
Программа предназначена для визуализации текущего состояния очередей пациентов, автоматической генерации отчетов и отправки уведомлений в Telegram.

## Основные возможности
- **Мониторинг в реальном времени**: Отслеживание статусов пациентов (Planned, On Treatment, Completed).
- **Telegram Бот**: Уведомления о новых планах, рассылка ежедневных отчетов.
- **Автоматические отчеты**: Генерация CSV-файлов по расписанию.
- **Индикация статуса БД**: Визуальный контроль подключения к PostgreSQL.
- **Управление прокси**: Автоматический запуск и остановка `xray` и `xmtproto`.

## Установка и запуск

### 1. Подготовка окружения
Рекомендуется использовать виртуальное окружение:
```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Настройка
Создайте файл `.env` для хранения секретов и `config.ini` для визуальных настроек.

### 3. Запуск
```bash
python teragis_pulse.py
```

## Структура проекта
- `teragis_pulse.py` — основной монолит приложения (GUI и логика).
- `database.py` — работа с базой данных PostgreSQL.
- `report_manager.py` — управление расписанием и логикой отчетов.
- `tg_bot.py` / `tg_bot_ws.py` — реализация Telegram бота.
- `proxy_manager.py` — управление внешними прокси-процессами.
- `identification.py` — логика разбора заметок и идентификации персонала.
- `constants.py` — справочники врачей и эмодзи.

## Разработка
Проект прошел этап модернизации кода (рефакторинг, типизация, обработка ошибок).
Для разработки используйте современные стандарты Python 3.10+.
